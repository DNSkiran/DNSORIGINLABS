02

In data/tools.json, set the matching release.repo, release.tag and exact release.assetName.

03

Verify the download

The public site checks GitHub Releases. The free download button activates only when the matching public asset exists.

INFRASTRUCTURE / CURRENT DESIGN

No hidden backend.

GitHub Pages serves static files. JSON documents are the content store. GitHub Releases hosts build downloads. GitHub's own login protects commits and settings. This meets the GitHub-only, no-personal-computer, ₹0 architecture without exposing secrets in the public client.
