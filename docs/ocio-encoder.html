DNS OCIO Encoder

A guide scaffold for the DNS OCIO Encoder, a desktop workflow concept for converting OpenEXR sequences into ProRes QuickTime movies with color management.

What it is designed to do

  • Read OpenEXR image sequences.
  • Apply a selected OpenColorIO configuration and transform as supported by the release.
  • Encode a QuickTime movie through FFmpeg.
  • Report output path, codec settings and errors.

Before installation

Check the release notes for supported Windows versions, bundled runtime components, required DLLs and supported OCIO configurations. Do not copy runtime libraries from an unrelated installation.

Basic workflow

  1. Choose the input EXR sequence and verify the frame range.
  2. Select the intended color configuration and output transform.
  3. Choose a supported ProRes profile and output destination.
  4. Run a short test range before encoding the full sequence.
  5. Inspect the movie for frame count, playback, color and metadata.

Diagnostics

  • Missing frames: confirm sequence pattern and first/last frame.
  • Color mismatch: confirm OCIO config, input color space and output transform.
  • Encoding failure: check available disk space, write permissions and the FFmpeg log.

Release status: no public binary release is linked yet. The download button will activate when a matching GitHub Release asset is published.

Documentation is a living reference. Verify tool version, production environment and release notes before using any workflow on production data.
